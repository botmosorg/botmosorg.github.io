Privacy, Disclaimer and Legal

  • The game does not set any cookies or use tracking analytics, and it does not want your personal data. Ephemeral session storage is used solely to pass your optional player handle and authentication to the game run. Session storage is deleted when you close the tab or when you press the "Clear BotMos Session Storage" button. You cannot comment on anything or signup for a newsletter.
  • The game and website are hosted on GitHub Pages (GitHub, Microsoft), see their terms and policies.
  • If you decide to do a leaderboard run, your run and optional credentials (username and salted password hash) are uploaded to a Cloudflare Worker and R2 bucket. This data is further processed by GitHub Actions and stored in the private BotMos GitHub monorepo. A subset of your leaderboard run data and your username are additionally stored in the public BotMos repository to provide the leaderboard page and replay service.
